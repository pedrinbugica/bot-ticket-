🤖 Bot de Administração

Um bot completo e profissional para gerenciar seu servidor Discord — tickets, moderação, XP, sorteios e muito mais.

Node.js 18+ discord.js v14 SQLite Multi-servidor Docker

O que é este bot?

Este é um bot de administração completo para Discord. Ele funciona em vários servidores ao mesmo tempo, cada um com suas próprias configurações separadas. Pensa nele como um "assistente digital" que cuida do seu servidor enquanto você não está olhando.

Tudo é configurado diretamente pelo Discord usando comandos /barra — não precisa editar nenhum arquivo de código para usar.

O que ele faz?

🎫

Sistema de Tickets

Painel bonito onde membros abrem chamados. A equipe assume, responde e fecha com transcript automático.

🔨

Moderação

Avise, silencie, expulse ou bane membros com um comando. Tudo fica registrado no histórico do servidor.

📋

Logs Automáticos

O bot registra tudo num canal: mensagens apagadas/editadas, quem entrou/saiu, bans, cargos alterados.

👋

Boas-vindas

Mensagem personalizada quando alguém entra. Dá cargo automaticamente para quem chegar.

🏷️

Menu de Cargos

Painel com dropdown onde membros escolhem seus próprios cargos — sem precisar pedir para ninguém.

😄

Reaction Roles

Reagiu com emoji = ganhou cargo. Removeu a reação = perdeu o cargo. Simples assim.

🛡️

Auto-Moderação

Bloqueia palavrões, spam, links e protege contra raids — sem precisar de moderador humano presente.

🎉

Sorteios

Cria sorteios com botão de participação. O bot sorteia automaticamente quando o tempo acaba.

📊

Enquetes

Votações com barras de progresso em tempo real. O resultado aparece automaticamente no prazo.

⭐

XP e Níveis

Membros ganham XP por conversar. Ao subir de nível, ganham cargos de recompensa automaticamente.

💬

Tags

Crie atalhos de resposta. Membro digita !ajuda e o bot responde com o texto que você configurou.

🗑️

Purge

Apaga até 100 mensagens de uma vez no canal atual. Pode filtrar por usuário para limpar só as mensagens de uma pessoa.

⭐

Starboard

Mensagens que recebem reações suficientes são copiadas para um canal de destaque — o "mural de fama" do servidor.

📊

Canais de Stats

Canais de voz com nomes que se atualizam automaticamente mostrando membros, canais, cargos e mais.

Requisitos

1

Node.js 18 ou superior

Baixe em nodejs.org e instale. Para verificar, abra o terminal e digite: node --version

2

Uma conta no Discord Developer Portal

Acesse discord.com/developers/applications com sua conta Discord normal e crie um novo aplicativo.

3

Um servidor Discord para testar

Crie um servidor só para testes. Isso evita acidentes no servidor principal durante a configuração.

Instalação passo a passo

Passo 1 — Instalar as dependências

Abra o terminal na pasta do projeto e rode:

npm install

Passo 2 — Criar o arquivo .env

Copie o arquivo de exemplo:

cp .env.example .env

Abra o .env num editor de texto e preencha o DISCORD_TOKEN (explicado no próximo passo).

Passo 3 — Iniciar o bot

npm start

Se aparecer "Conectado como NomeDoBot#0000" no terminal, o bot está funcionando!

⚠️ Atenção Nunca compartilhe o conteúdo do arquivo .env com ninguém — ele contém o token secreto do bot.

Configuração no Discord Developer Portal

ℹ️ Por que isso é necessário? O Discord exige que o dono do bot ative manualmente certas "permissões especiais" (intents privilegiadas) para que o bot consiga ler mensagens e ver membros do servidor.
1

Criar o aplicativo

Acesse discord.com/developers/applications → clique em New Application → dê um nome.

2

Copiar o Token

Vá em Bot no menu lateral → clique em Reset Token → copie o token e cole no .env no campo DISCORD_TOKEN.

3

Ativar as Intents Privilegiadas

Ainda em Bot, role a página para baixo até Privileged Gateway Intents e ative:

  • ✅ Server Members Intent — ver quem entra/sai do servidor
  • ✅ Message Content Intent — ler o conteúdo das mensagens (necessário para auto-mod, XP e tags)
4

Convidar o bot para seu servidor

Vá em OAuth2 → URL Generator, marque os escopos bot e applications.commands. Em Bot Permissions, marque:

  • Manage Roles
  • Kick Members
  • Ban Members
  • Moderate Members
  • Send Messages
  • Manage Messages
  • Read Message History
  • Embed Links
  • Add Reactions
  • View Channels

Copie a URL gerada, abra no navegador e selecione o servidor de testes.

🎫 Sistema de Tickets

Cria um painel de atendimento onde membros abrem chamados. A equipe pode assumir, adicionar membros e fechar com transcript automático.

Como configurar

Use /config painel para abrir o painel visual e configurar categoria, canal de logs e cargos de suporte.

Comandos

ComandoO que faz
/ticket-painelEnvia o painel de abertura de tickets num canal
/ticket add @usuarioAdiciona um membro ao ticket atual
/ticket remove @usuarioRemove um membro do ticket
/ticket statsEstatísticas de tickets do servidor

🔨 Moderação

Ferramentas para a equipe punir membros. Toda ação gera um caso numerado que fica no histórico do servidor.

Comandos

ComandoO que faz
/mod warn @user [motivo]Aplica um aviso. O membro recebe DM com o motivo.
/mod mute @user 10m [motivo]Silencia por tempo. Formatos: 10m, 1h, 2d (máx. 28d)
/mod kick @user [motivo]Expulsa do servidor (pode voltar)
/mod ban @user [motivo]Bane permanentemente
/mod historico @userLista todas as infrações de um usuário
/mod casosLista os 10 casos mais recentes do servidor
/mod remover caso:5Inativa um caso pelo número

📋 Logs do Servidor

O bot registra automaticamente tudo que acontece num canal configurado. Você escolhe quais eventos monitorar.

Como configurar

Use /config painel → clique na tela Logs → selecione o canal de logs → ative os eventos desejados.

Eventos disponíveis

EventoQuando dispara
Mensagem editadaAlguém edita uma mensagem (mostra o antes e depois)
Mensagem apagadaAlguém apaga uma mensagem
Membro entrouNova pessoa entra no servidor
Membro saiuAlguém sai ou é expulso
BanUm membro é banido
UnbanUm ban é removido
Cargo alteradoCargo adicionado ou removido de um membro
Apelido alteradoApelido do servidor alterado

👋 Boas-vindas

Envia uma mensagem automática quando alguém entra ou sai do servidor. Também pode atribuir um cargo automaticamente.

Como configurar

Use /config painel → clique em Boas-vindas → configure canal, mensagem e cargo automático.

Variáveis disponíveis na mensagem

VariávelSubstitui por
{usuario}Menção do membro (ex: @Pedro)
{tag}Nome de usuário completo (ex: Pedro#1234)
{servidor}Nome do servidor
{membros}Número total de membros

Exemplo de mensagem: Bem-vindo ao {servidor}, {usuario}! Você é o membro número {membros}. 🎉

🏷️ Menu de Cargos e Reaction Roles

Menu de Cargos (Dropdown)

Cria um painel com um menu dropdown onde membros escolhem seus próprios cargos sem precisar pedir para ninguém.

ComandoO que faz
/cargo-menu criar #canal TítuloCria um novo menu de cargos no canal informado
/cargo-menu opcao-adicionar menu_id:1 cargo:@MembroAdiciona uma opção ao menu
/cargo-menu opcao-remover menu_id:1 cargo:@MembroRemove uma opção do menu
/cargo-menu remover menu_id:1Apaga o menu
/cargo-menu listaLista todos os menus do servidor

Reaction Roles (Por Emoji)

Associa um emoji de uma mensagem específica a um cargo. Reagir = ganhar cargo. Remover reação = perder cargo.

ComandoO que faz
/reaction-role adicionar #canal ID_MENSAGEM 👍 @CargoCria reaction role
/reaction-role remover id:1Remove reaction role pelo ID
/reaction-role listaLista todas as reaction roles
ℹ️ Como pegar o ID de uma mensagem Ative o "Modo Desenvolvedor" no Discord (Configurações → Avançado → Modo Desenvolvedor), depois clique com o botão direito na mensagem e escolha "Copiar ID".

🛡️ Auto-Moderação

O bot monitora todas as mensagens e age automaticamente, sem precisar de moderador humano presente.

ComandoO que faz
/automod verMostra todas as configurações atuais
/automod palavra-adicionar palavra:xingamento acao:muteAdiciona palavra proibida. Ações: delete, warn, mute
/automod palavra-remover palavra:xingamentoRemove palavra da lista
/automod palavras-listaMostra todas as palavras proibidas
/automod spam ativo:Sim mensagens:5 segundos:5 acao:muteAtiva anti-spam: 5 mensagens em 5 segundos = mute
/automod mencoes limite:5Apaga mensagens com mais de 5 @menções
/automod links ativo:SimBloqueia links e convites do Discord
/automod raid ativo:Sim entradas:10 segundos:30Alerta quando 10 pessoas entram em 30 segundos
/automod isentar-canal #geralO bot ignora esse canal
/automod isentar-cargo @ModeradorO bot ignora membros com esse cargo

🎉 Sorteios

Cria sorteios com um botão de participação. Quando o tempo acabar, o bot sorteia os vencedores automaticamente e anuncia no canal.

ComandoO que faz
/sorteio criar premio:Nitro duracao:1hCria sorteio de 1 hora com 1 vencedor
/sorteio criar premio:Nitro duracao:1d vencedores:3 canal:#sorteiosSorteio com 3 vencedores num canal específico
/sorteio encerrar id:1Encerra o sorteio agora mesmo
/sorteio reroll id:1 vencedores:1Sorteia um novo vencedor (se o ganhador não aparecer)
/sorteio listaLista todos os sorteios ativos
✅ Duração suportada Formatos: 10m (10 minutos), 1h (1 hora), 2d (2 dias). Máximo: 30 dias.

📊 Enquetes

Cria votações com até 5 opções e botões clicáveis. O placar atualiza em tempo real e o resultado aparece automaticamente quando o prazo vence.

ComandoO que faz
/enquete criar pergunta:Qual cor? opcao1:Azul opcao2:VerdeCria enquete sem prazo (encerra em 7 dias)
/enquete criar pergunta:... opcao1:A opcao2:B opcao3:C duracao:2hEnquete com 3 opções e prazo de 2 horas
/enquete encerrar id:1Encerra e publica resultado agora
/enquete listaLista enquetes abertas
ℹ️ Trocar voto Membros podem trocar o voto clicando em outra opção. Clicar na mesma opção mostra aviso de "já votou".

⭐ XP e Níveis

Membros ganham XP por enviar mensagens (com cooldown para evitar spam). Ao subir de nível, recebem notificação e podem ganhar cargos de recompensa automaticamente.

Fórmula de nível

Nível = raiz quadrada de (XP ÷ 100). Na prática: nível 1 = 100 XP, nível 5 = 2.500 XP, nível 10 = 10.000 XP.

ComandoO que faz
/nivelVê seu próprio nível, XP e barra de progresso
/nivel usuario:@PedroVê o nível de outro membro
/topRanking dos 10 mais ativos do servidor
/top pagina:2Segunda página do ranking
/xp config ativar:SimAtiva o sistema de XP
/xp config ativar:Sim canal:#level-up xp_mensagem:20 cooldown:60Configuração completa
/xp configMostra a configuração atual (sem parâmetros)
/xp reset usuario:@PedroZera o XP de um membro
/xp recompensa-adicionar nivel:5 cargo:@VeteranoCargo automático ao atingir nível 5
/xp recompensa-remover nivel:5Remove a recompensa do nível 5
/xp recompensasLista todas as recompensas configuradas

💬 Tags (Respostas Automáticas)

Crie atalhos de texto. Quando alguém digita o prefixo + nome da tag no chat, o bot responde automaticamente com o conteúdo configurado.

Exemplo: Admin cria a tag ajuda. Qualquer membro digita !ajuda no chat e o bot responde.

ComandoO que faz
/tag criar nome:ajuda conteudo:Leia as regras em #regras!Cria a tag !ajuda
/tag editar nome:ajuda conteudo:Novo texto aquiAtualiza o conteúdo
/tag remover nome:ajudaApaga a tag
/tag listaLista todas as tags e quantas vezes foram usadas
/tag ver nome:ajudaMostra o conteúdo da tag
/tag prefixo prefixo:?Muda o prefixo de ! para ?
⚠️ Segurança O conteúdo das tags nunca consegue pingar @everyone ou cargos — isso é bloqueado automaticamente.

🗑️ Purge — Apagar mensagens em massa

O comando /mod purge apaga várias mensagens de um canal de uma vez. Pense nele como uma "vassoura" que limpa o canal rapidinho — sem precisar selecionar mensagem por mensagem.

⚠️ Limitação do Discord Só é possível apagar em massa mensagens com menos de 14 dias. Mensagens mais antigas precisam ser apagadas uma a uma.

Como usar

ComandoO que faz
/mod purge quantidade:50 Apaga as últimas 50 mensagens do canal (de qualquer pessoa)
/mod purge quantidade:20 usuario:@Pedro Apaga as últimas 20 mensagens enviadas especificamente pelo Pedro

Permissão necessária

Apenas membros com a permissão Gerenciar mensagens conseguem usar este comando.

Passo a passo para usar

1

Vá ao canal que quer limpar

O purge apaga mensagens do canal onde o comando for digitado.

2

Digite o comando

Use /mod purge quantidade:50 para limpar 50 mensagens. Se quiser limpar só de uma pessoa, adicione usuario:@Nome.

3

Confirme o resultado

O bot responde com uma mensagem mostrando quantas mensagens foram apagadas (só você vê essa resposta).

⭐ Starboard — Mensagens em destaque

O Starboard é um canal especial onde as mensagens mais curtidas do servidor aparecem automaticamente. Quando uma mensagem recebe uma certa quantidade de reações ⭐ (ou outro emoji que você escolher), o bot copia ela para o canal do starboard.

Pense nele como um "mural de fama" — as melhores mensagens do servidor ficam guardadas ali para todo mundo ver.

Como ativar (passo a passo)

1

Crie um canal para o starboard

Crie um canal de texto no Discord, por exemplo #⭐-starboard ou #melhores-momentos. Só o bot precisa ter permissão de enviar mensagens lá.

2

Configure com o comando

Use /starboard configurar canal:#⭐-starboard. Você pode também mudar o emoji e o mínimo de reações.

3

Teste!

Envie uma mensagem em qualquer canal e peça para alguém reagir com ⭐. Quando atingir o mínimo configurado, o bot vai copiar automaticamente para o canal do starboard.

Comandos disponíveis

ComandoO que faz
/starboard configurar canal:#starboard Ativa o starboard no canal escolhido com as configurações padrão (⭐, mínimo 3)
/starboard configurar canal:#starboard emoji:🔥 minimo:5 Usa o emoji 🔥 e exige 5 reações para entrar no starboard
/starboard ver Mostra a configuração atual (canal, emoji, mínimo de reações, status)
/starboard desativar Pausa o starboard sem apagar a configuração. Para reativar, use configurar novamente.
ℹ️ Como funciona por dentro Quando a contagem de reações muda (alguém adiciona ou remove), o bot atualiza a mensagem no starboard automaticamente mostrando o número atual. A mensagem original nunca é apagada do canal onde foi enviada.
⚠️ Atenção O starboard não funciona para mensagens de bots. Também não copia mensagens enviadas dentro do próprio canal do starboard (para evitar loops).

📊 Canais de Estatísticas

Os canais de estatísticas são canais de voz com nomes que se atualizam automaticamente mostrando números do servidor — como total de membros, quantidade de canais, etc. Pense neles como um "placar ao vivo" do servidor visível na barra lateral para todo mundo.

✅ Dica visual Use canais de voz para isso — membros não conseguem escrever neles, então o nome atualizado fica limpo e não "suja" com mensagens. Crie uma categoria separada chamada "📊 Servidor" para organizar.

Tipos de estatísticas disponíveis

TipoO que mostraExemplo de nome
membrosTotal de membros (humanos + bots)👥 Membros: 1.234
humanosApenas membros humanos (sem bots)🧑 Humanos: 1.229
botsQuantidade de bots no servidor🤖 Bots: 5
canaisTotal de canais (texto + voz + categoria)📢 Canais: 42
cargosTotal de cargos criados no servidor🏷️ Cargos: 18

Como configurar (passo a passo)

1

Crie uma categoria e canais de voz

No Discord, crie uma categoria chamada 📊 Estatísticas. Dentro dela, crie canais de voz com qualquer nome provisório — o bot vai renomeá-los.

2

Tire a permissão de "Conectar" dos membros

Nas permissões da categoria, remova a permissão Conectar de @everyone — assim ninguém entra no canal, ele fica apenas visual.

3

Use o comando para vincular

Para cada tipo de stat que quiser mostrar, use /stats criar tipo:[tipo] canal:[canal de voz]. O bot atualiza o nome na hora e depois a cada 10 minutos.

Comandos disponíveis

ComandoO que faz
/stats criar tipo:membros canal:#membros-totais Vincula o canal ao contador de membros totais com o formato padrão
/stats criar tipo:membros canal:#membros formato:🌍 Total: {value} Usa um formato personalizado. O {value} é substituído pelo número real
/stats lista Mostra todos os canais de stats configurados com seus formatos
/stats remover tipo:membros Remove a vinculação (o canal continua existindo, só para de ser atualizado)
/stats atualizar Força atualização imediata de todos os canais sem esperar os 10 minutos
⚠️ Limite do Discord O Discord permite renomear um canal no máximo 2 vezes por 10 minutos. Por isso o bot atualiza em intervalos de 10 minutos para não ser bloqueado pela API. Se usar /stats atualizar seguidas vezes, algumas atualizações podem ser ignoradas.
