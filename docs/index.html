🤖 Bot de Administração

Um bot completo e profissional para gerenciar seu servidor Discord — tickets, moderação, XP, sorteios e muito mais.

Node.js 18+ discord.js v14 SQLite Multi-servidor Docker

O que é este bot?

Este é um bot de administração completo para Discord. Ele funciona em vários servidores ao mesmo tempo, cada um com suas próprias configurações separadas. Pensa nele como um "assistente digital" que cuida do seu servidor enquanto você não está olhando.

Tudo é configurado diretamente pelo Discord usando comandos /barra — não precisa editar nenhum arquivo de código para usar.

O que ele faz?

🎫

Sistema de Tickets

Painel bonito onde membros abrem chamados. A equipe assume, responde e fecha com transcript automático.

🔨

Moderação

Avise, silencie, expulse ou bane membros com um comando. Tudo fica registrado no histórico do servidor.

📋

Logs Automáticos

O bot registra tudo num canal: mensagens apagadas/editadas, quem entrou/saiu, bans, cargos alterados.

👋

Boas-vindas

Mensagem personalizada quando alguém entra. Dá cargo automaticamente para quem chegar.

🏷️

Menu de Cargos

Painel com dropdown onde membros escolhem seus próprios cargos — sem precisar pedir para ninguém.

😄

Reaction Roles

Reagiu com emoji = ganhou cargo. Removeu a reação = perdeu o cargo. Simples assim.

🛡️

Auto-Moderação

Bloqueia palavrões, spam, links e protege contra raids — sem precisar de moderador humano presente.

🎉

Sorteios

Cria sorteios com botão de participação. O bot sorteia automaticamente quando o tempo acaba.

📊

Enquetes

Votações com barras de progresso em tempo real. O resultado aparece automaticamente no prazo.

⭐

XP e Níveis

Membros ganham XP por conversar. Ao subir de nível, ganham cargos de recompensa automaticamente.

💬

Tags

Crie atalhos de resposta. Membro digita !ajuda e o bot responde com o texto que você configurou.

🗑️

Purge

Apaga até 100 mensagens de uma vez no canal atual. Pode filtrar por usuário para limpar só as mensagens de uma pessoa.

⭐

Starboard

Mensagens que recebem reações suficientes são copiadas para um canal de destaque — o "mural de fama" do servidor.

📊

Canais de Stats

Canais de voz com nomes que se atualizam automaticamente mostrando membros, canais, cargos e mais.

⏱️

Slow Mode & TempBan

Modo lento por canal com um comando. Banimento temporário: o bot desbane sozinho quando o prazo vencer.

🔢

Counting Game

Jogo de contagem num canal dedicado. O bot reage a cada número e reseta se alguém errar ou contar duas vezes seguidas.

✏️

Embed Builder

Crie embeds bonitas com título, descrição, cor e imagem via formulário visual — sem precisar saber JSON.

🎂

Aniversários

Membros registram seu aniversário e o bot parabeniza automaticamente no canal configurado no dia certo.

📅

Mensagens Agendadas

Agende mensagens para serem enviadas num canal em data e hora futura — o bot envia sozinho no horário certo.

🎮

Join-to-Create

Canal de voz "gatilho" que cria salas temporárias para cada membro. Quando a sala esvazia, o bot a apaga.

🎤

XP em Voz

Membros ganham XP por tempo em canais de voz. Multiplicadores por canal ou cargo para áreas prioritárias.

Requisitos

1

Node.js 18 ou superior

Baixe em nodejs.org e instale. Para verificar, abra o terminal e digite: node --version

2

Uma conta no Discord Developer Portal

Acesse discord.com/developers/applications com sua conta Discord normal e crie um novo aplicativo.

3

Um servidor Discord para testar

Crie um servidor só para testes. Isso evita acidentes no servidor principal durante a configuração.

Instalação passo a passo

Passo 1 — Instalar as dependências

Abra o terminal na pasta do projeto e rode:

npm install

Passo 2 — Criar o arquivo .env

Copie o arquivo de exemplo:

cp .env.example .env

Abra o .env num editor de texto e preencha o DISCORD_TOKEN (explicado no próximo passo).

Passo 3 — Iniciar o bot

npm start

Se aparecer "Conectado como NomeDoBot#0000" no terminal, o bot está funcionando!

⚠️ Atenção Nunca compartilhe o conteúdo do arquivo .env com ninguém — ele contém o token secreto do bot.

Configuração no Discord Developer Portal

ℹ️ Por que isso é necessário? O Discord exige que o dono do bot ative manualmente certas "permissões especiais" (intents privilegiadas) para que o bot consiga ler mensagens e ver membros do servidor.
1

Criar o aplicativo

Acesse discord.com/developers/applications → clique em New Application → dê um nome.

2

Copiar o Token

Vá em Bot no menu lateral → clique em Reset Token → copie o token e cole no .env no campo DISCORD_TOKEN.

3

Ativar as Intents Privilegiadas

Ainda em Bot, role a página para baixo até Privileged Gateway Intents e ative:

  • ✅ Server Members Intent — ver quem entra/sai do servidor
  • ✅ Message Content Intent — ler o conteúdo das mensagens (necessário para auto-mod, XP e tags)
4

Convidar o bot para seu servidor

Vá em OAuth2 → URL Generator, marque os escopos bot e applications.commands. Em Bot Permissions, marque:

  • Manage Roles
  • Kick Members
  • Ban Members
  • Moderate Members
  • Send Messages
  • Manage Messages
  • Read Message History
  • Embed Links
  • Add Reactions
  • View Channels

Copie a URL gerada, abra no navegador e selecione o servidor de testes.

🔨 Moderação

Ferramentas para a equipe punir membros. Toda ação gera um caso numerado que fica no histórico do servidor.

Comandos

⭐ XP e Níveis

Membros ganham XP por enviar mensagens (com cooldown para evitar spam). Ao subir de nível, recebem notificação e podem ganhar cargos de recompensa automaticamente.

Fórmula de nível

Nível = raiz quadrada de (XP ÷ 100). Na prática: nível 1 = 100 XP, nível 5 = 2.500 XP, nível 10 = 10.000 XP.

ComandoO que faz
/nivelVê seu próprio nível, XP e barra de progresso
/nivel usuario:@PedroVê o nível de outro membro
/topRanking dos 10 mais ativos do servidor
/top pagina:2Segunda página do ranking
/xp config ativar:SimAtiva o sistema de XP
/xp config ativar:Sim canal:#level-up xp_mensagem:20 cooldown:60Configuração completa
/xp configMostra a configuração atual (sem parâmetros)
/xp reset usuario:@PedroZera o XP de um membro
/xp recompensa-adicionar nivel:5 cargo:@VeteranoCargo automático ao atingir nível 5
/xp recompensa-remover nivel:5Remove a recompensa do nível 5
/xp recompensasLista todas as recompensas configuradas

🎤 XP em Voz

Membros que ficam em canais de voz ganham XP a cada minuto (exceto AFK e surdos). Você pode definir multiplicadores por canal ou cargo para recompensar áreas prioritárias.

ComandoO que faz
/xp vozMostra a configuração atual de XP em voz
/xp voz ativar:Sim xp_por_minuto:10Ativa XP em voz e define 10 XP por minuto
/xp voz ativar:NãoDesativa XP em voz
/xp multiplicador-canal canal:#gaming multiplicador:2Dobra o XP no canal #gaming
/xp multiplicador-canal canal:#gaming multiplicador:0Remove o multiplicador do canal (use 0 para remover)
/xp multiplicador-cargo cargo:@VIP multiplicador:1.5Membros VIP ganham 50% a mais de XP
/xp multiplicadoresLista todos os multiplicadores de canal e cargo configurados
ℹ️ Como funciona o multiplicador O bot aplica o maior multiplicador entre canal e cargo — eles não se somam. Exemplo: canal 2x e cargo 1.5x → o membro recebe 2x (o maior).

🗑️ Purge — Apagar mensagens em massa

O comando /mod purge apaga várias mensagens de um canal de uma vez. Pense nele como uma "vassoura" que limpa o canal rapidinho — sem precisar selecionar mensagem por mensagem.

⚠️ Limitação do Discord Só é possível apagar em massa mensagens com menos de 14 dias. Mensagens mais antigas precisam ser apagadas uma a uma.

Como usar

ComandoO que faz
/mod purge quantidade:50 Apaga as últimas 50 mensagens do canal (de qualquer pessoa)
/mod purge quantidade:20 usuario:@Pedro Apaga as últimas 20 mensagens enviadas especificamente pelo Pedro

Permissão necessária

Apenas membros com a permissão Gerenciar mensagens conseguem usar este comando.

Passo a passo para usar

1

Vá ao canal que quer limpar

O purge apaga mensagens do canal onde o comando for digitado.

2

Digite o comando

Use /mod purge quantidade:50 para limpar 50 mensagens. Se quiser limpar só de uma pessoa, adicione usuario:@Nome.

3

Confirme o resultado

O bot responde com uma mensagem mostrando quantas mensagens foram apagadas (só você vê essa resposta).

⭐ Starboard — Mensagens em destaque

O Starboard é um canal especial onde as mensagens mais curtidas do servidor aparecem automaticamente. Quando uma mensagem recebe uma certa quantidade de reações ⭐ (ou outro emoji que você escolher), o bot copia ela para o canal do starboard.

Pense nele como um "mural de fama" — as melhores mensagens do servidor ficam guardadas ali para todo mundo ver.

Como ativar (passo a passo)

1

Crie um canal para o starboard

Crie um canal de texto no Discord, por exemplo #⭐-starboard ou #melhores-momentos. Só o bot precisa ter permissão de enviar mensagens lá.

2

Configure com o comando

Use /starboard configurar canal:#⭐-starboard. Você pode também mudar o emoji e o mínimo de reações.

3

Teste!

Envie uma mensagem em qualquer canal e peça para alguém reagir com ⭐. Quando atingir o mínimo configurado, o bot vai copiar automaticamente para o canal do starboard.

Comandos disponíveis

ComandoO que faz
/starboard configurar canal:#starboard Ativa o starboard no canal escolhido com as configurações padrão (⭐, mínimo 3)
/starboard configurar canal:#starboard emoji:🔥 minimo:5 Usa o emoji 🔥 e exige 5 reações para entrar no starboard
/starboard ver Mostra a configuração atual (canal, emoji, mínimo de reações, status)
/starboard desativar Pausa o starboard sem apagar a configuração. Para reativar, use configurar novamente.
ℹ️ Como funciona por dentro Quando a contagem de reações muda (alguém adiciona ou remove), o bot atualiza a mensagem no starboard automaticamente mostrando o número atual. A mensagem original nunca é apagada do canal onde foi enviada.
⚠️ Atenção O starboard não funciona para mensagens de bots. Também não copia mensagens enviadas dentro do próprio canal do starboard (para evitar loops).

📊 Canais de Estatísticas

Os canais de estatísticas são canais de voz com nomes que se atualizam automaticamente mostrando números do servidor — total de membros, boosts, tickets abertos e mais. Pense neles como um "placar ao vivo" visível na barra lateral do Discord para todo mundo.

✅ O bot cria o canal sozinho! Não precisa criar nada manualmente. Só use o comando /stats criar e o bot já cria o canal de voz, bloqueia membros de entrar e coloca o número certo no nome.

Como usar — é só um comando

1

(Opcional) Crie uma categoria para organizar

Se quiser deixar os canais de stats agrupados, crie uma categoria no Discord chamada 📊 Servidor por exemplo. Não é obrigatório.

2

Use o comando

Digite /stats criar tipo:membros — o bot cria o canal de voz na hora com o nome já atualizado. Se quiser colocar dentro de uma categoria, adicione categoria:#nome-da-categoria.

3

Pronto!

O canal já aparece na barra lateral com o número real. Atualiza automaticamente a cada 10 minutos. Repita para cada tipo de stat que quiser.

Tipos disponíveis (9 no total)

TipoO que mostraNome padrão do canal
membrosTotal de membros (humanos + bots)👥 Membros: 1.234
humanosSó membros humanos (sem bots)🧑 Humanos: 1.229
botsQuantidade de bots no servidor🤖 Bots: 5
canaisTotal de canais (texto + voz + categoria)📢 Canais: 42
cargosTotal de cargos criados no servidor🏷️ Cargos: 18
boostsQuantidade de boosts ativos no servidor🚀 Boosts: 7
nivel-boostNível de boost do servidor (0, 1, 2 ou 3)💎 Boost Nível 2
emojisQuantidade de emojis personalizados😄 Emojis: 64
ticketsTickets de suporte abertos agora🎫 Tickets abertos: 3

Comandos disponíveis

ComandoO que faz
/stats criar tipo:membros Cria um canal de voz com o contador de membros totais (nome padrão automático)
/stats criar tipo:boosts categoria:#📊-servidor Cria o canal dentro de uma categoria específica do servidor
/stats criar tipo:membros formato:🌍 Comunidade: {value} Usa um nome personalizado — o {value} é trocado pelo número real
/stats lista Mostra todos os canais de stats ativos e seus tipos
/stats remover tipo:membros Remove o stat e apaga o canal de voz do servidor automaticamente
/stats atualizar Força atualização imediata de todos os canais sem esperar os 10 minutos
ℹ️ Sobre o formato personalizado Você pode mudar o nome do canal como quiser usando o parâmetro formato. O {value} é onde o número entra. Exemplos:

formato:🌍 Comunidade: {value} → 🌍 Comunidade: 1.234
formato:💎 Nível {value} de boost → 💎 Nível 2 de boost
⚠️ Limite do Discord O Discord só permite renomear um canal 2 vezes por 10 minutos. Por isso o bot atualiza nesse intervalo. Se usar /stats atualizar várias vezes seguidas, o Discord pode ignorar algumas — isso é normal.

⏱️ Slow Mode & Banimento Temporário

Dois recursos de moderação que trabalham no tempo — slow mode limita a velocidade de mensagens num canal, e o tempban bane por um prazo e desbane automaticamente.

Slow Mode

Define um intervalo mínimo entre mensagens num canal. Ideal para conter agitação em momentos de pico sem precisar silenciar ninguém.

ComandoO que faz
/mod slowmode canal:#geral duracao:30s30 segundos entre mensagens no #geral
/mod slowmode canal:#geral duracao:5m5 minutos entre mensagens
/mod slowmode canal:#geral duracao:0Desativa o modo lento (volta ao normal)
ℹ️ Formatos aceitos 0 (off), 30s, 1m, 10m, 1h — máximo 6 horas.

Banimento Temporário (TempBan)

Bane o membro por um prazo definido. Quando o prazo vencer, o bot processa automaticamente o desbanimento — não precisa de intervenção manual.

ComandoO que faz
/mod tempban @user duracao:1hBane por 1 hora, desbane automaticamente
/mod tempban @user duracao:7d motivo:Comportamento impróprioBane por 7 dias com motivo registrado
⚠️ Auto-escalação de advertências O sistema de warn tem escalação automática: ao acumular 3 warns o membro leva mute de 1 hora; ao chegar em 5 warns é expulso automaticamente. Ambas as ações geram um caso de moderação separado.

🔢 Counting Game

Um jogo de contagem colaborativo. Os membros enviam números em sequência num canal dedicado, e o bot reage com ✅ quando está certo. Errar o número ou contar duas vezes seguidas reseta a contagem para zero e o bot avisa todo mundo.

Como ativar

1

Crie um canal de texto

Crie um canal chamado #🔢-contagem ou similar. Só números devem ir lá — outros textos são apagados automaticamente.

2

Configure com o comando

Use /counting configurar canal:#🔢-contagem.

3

Comece a contar!

Qualquer membro envia 1 no canal. O próximo membro (diferente) manda 2, e assim por diante.

Comandos

ComandoO que faz
/counting configurar canal:#contagemDefine o canal do jogo de contagem
/counting verMostra canal, número atual e recorde do servidor
/counting desativarDesativa e remove o canal de contagem

Regras do jogo

SituaçãoO que acontece
Número correto✅ reação — contagem avança
Número errado❌ reação + mensagem de erro — contagem reseta para 0
Mesmo usuário contando duas vezesMensagem apagada — contagem não reseta, mas o número não avança
Múltiplo de 100🎉 mensagem de celebração no canal
Texto que não é númeroMensagem apagada silenciosamente

✏️ Embed Builder

Cria embeds bonitas com aparência profissional em qualquer canal de texto — sem precisar saber JSON ou usar bots externos. Um formulário visual abre com campos de título, descrição, cor, rodapé e imagem.

Como usar

1

Digite o comando

Use /embed (envia no canal atual) ou /embed canal:#anuncios para escolher o destino.

2

Preencha o formulário

Um pop-up abre com os campos: Título, Descrição, Cor (ex: #5865F2), Rodapé e URL da imagem.

3

Envie

Clique em Enviar e o bot posta a embed imediatamente no canal escolhido.

🎂 Aniversários

Membros registram o dia e mês do seu aniversário. Todo dia o bot verifica quem faz aniversário e manda parabéns automaticamente num canal configurado pela administração.

Para os membros

ComandoO que faz
/aniversario registrar dia:15 mes:3Registra seu aniversário para 15 de março
/aniversario verVê a data do seu próprio aniversário
/aniversario ver usuario:@PedroVê o aniversário de outro membro
/aniversario removerRemove o seu aniversário do registro

Para administradores

ComandoO que faz
/aniversario configurar canal:#aniversáriosDefine o canal onde o parabéns será enviado
/aniversario configurar mensagem:🎂 Hoje é aniversário de {usuario}! Feliz aniversário! 🎉Define a mensagem personalizada
ℹ️ Variável disponível Use {usuario} na mensagem — o bot substitui pela menção do membro (ex: @Pedro).
⚠️ Só dia e mês O bot guarda apenas o dia e o mês — sem o ano. Isso protege a privacidade dos membros.

📅 Mensagens Agendadas

Agende uma mensagem para ser enviada num canal em uma data e hora futura. O bot verifica a cada minuto e envia no momento certo — sem precisar estar online.

Como usar

ComandoO que faz
/agendar criar canal:#anuncios mensagem:Bem-vindos ao evento! quando:20/07/2026 20:00 Agenda a mensagem para 20 de julho de 2026 às 20h
/agendar listaLista todas as mensagens pendentes com ID, canal, data e prévia do texto
/agendar cancelar id:3Cancela a mensagem de ID 3 antes de ser enviada
ℹ️ Formato da data Use DD/MM/AAAA HH:MM — exemplo: 01/06/2026 20:00. A data precisa ser no futuro.
⚠️ Precisão O bot verifica a cada 1 minuto, então a mensagem pode ser enviada com até 1 minuto de atraso em relação ao horário exato.

🎮 Join-to-Create (Voz Temporária)

Cria um sistema de salas de voz sob demanda. Você configura um canal "gatilho": quando alguém entra nele, o bot cria uma sala de voz exclusiva para aquela pessoa e a move para lá. Quando a sala fica vazia, o bot apaga automaticamente.

Como ativar

1

Crie o canal gatilho

Crie um canal de voz chamado ➕ Criar Sala ou similar. Este canal só serve como "botão" — o bot vai mover a pessoa para a sala criada.

2

Configure com o comando

Use /jtc configurar canal:#criar-sala. Você pode também definir uma categoria e um modelo de nome.

3

Teste!

Entre no canal gatilho — o bot cria uma sala e te move para lá. Ao sair, a sala é apagada.

Comandos

ComandoO que faz
/jtc configurar canal:#criar-salaDefine o canal gatilho com o nome padrão 🎮 {username}
/jtc configurar canal:#criar-sala nome:🔊 Sala de {username} categoria:#SalasCanal gatilho, nome personalizado e categoria para as salas temporárias
/jtc verMostra a configuração atual
/jtc desativarDesativa o sistema (não apaga as salas já criadas)
ℹ️ Variável no nome Use {username} no modelo de nome — o bot substitui pelo apelido do membro no servidor. Ex: 🎮 {username} → 🎮 Pedro.
⚠️ Permissão necessária no bot O bot precisa de Gerenciar canais e Mover membros para criar e deletar salas e mover o membro para a nova sala.

✅ Guia completo de testes

Marque cada item conforme for testando. Recomendamos ter duas contas Discord (a sua e uma conta de teste) para simular um membro comum.

ℹ️ Antes de começar Inicie o bot (npm start), convide-o para o servidor de testes e certifique-se que ele tem a role mais alta possível (acima das roles que vai gerenciar). Espere o terminal mostrar "Conectado como ...".
