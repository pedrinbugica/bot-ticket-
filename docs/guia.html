☁️ Hospedar no DisCloud

O DisCloud é um serviço gratuito para manter o bot online 24h por dia. Siga estes passos:

1

Criar conta no DisCloud

Acesse discloud.app, faça login com a sua conta do Discord e confirme o e-mail.

2

Compactar o projeto em .zip

Selecione todos os arquivos do projeto exceto a pasta node_modules e a pasta .git. Compacte em um arquivo .zip.

3

Fazer upload no DisCloud

No painel do DisCloud, clique em "Add App", selecione o tipo Bot, e faça o upload do .zip. O DisCloud instala as dependências automaticamente.

4

Configurar as variáveis de ambiente

No painel do app criado, clique em "Envs" e adicione as variáveis (veja a seção abaixo). Depois clique em "Start".

💡
O arquivo discloud.config já está incluído no projeto com as configurações corretas — você não precisa criar nem editar esse arquivo.

🔑 Variáveis de ambiente

Estas são as variáveis que você precisa configurar no painel do DisCloud (aba Envs):

VariávelObrigatória?O que é
DISCORD_TOKEN✅ SimToken secreto do bot. Pegar em discord.com/developers → seu app → Bot → "Reset Token".
DEPLOY_GLOBAL❌ NãoUse true para registrar comandos globalmente (demora ~1h) ou false para registrar só nos servidores onde o bot está (imediato). Padrão: false.

ℹ️
As configurações de cada servidor (canais, cargos, mensagens) são feitas pelos admins de cada servidor diretamente pelo Discord, usando o comando /configurar. Não precisam ir no .env.

⚙️ Comando /configurar

Este é o comando principal para os admins de cada servidor configurarem o bot. Só funciona para quem tem a permissão "Gerenciar servidor" no Discord.

🎫 Sistema de Tickets

O sistema de tickets cria canais privados de atendimento quando um membro clica em um botão. Ideal para suporte, denúncias ou relatórios.

/config painel Abre o painel visual de configuração de tickets 🔒 Admin

Abre um menu interativo para configurar todos os detalhes dos tickets do servidor: categoria, canal de log, cargos de suporte, cores, título, mensagem de regras, etc.

ℹ️
Use este comando primeiro para configurar o sistema. Depois use /ticket-painel para enviar o botão de abertura num canal público.
/ticket-painel Envia o painel de abertura de tickets no canal atual 🔒 Admin

Envia um embed bonito com um botão para os membros abrirem tickets. Use este comando no canal público onde você quer que os membros peçam suporte.

/ticket add / remove / stats Ações dentro de um ticket aberto ✅ Membros da equipe
  • /ticket add @usuario — Adiciona um membro ao ticket atual
  • /ticket remove @usuario — Remove um membro do ticket
  • /ticket stats — Mostra estatísticas de tickets do servidor

🔨 Moderação

Ferramentas para punir membros que violam as regras. Todas as ações ficam salvas no histórico do servidor.

/mod warn / mute / kick / ban Aplicar punições a membros 🔒 Moderar membros
  • /mod warn @usuario motivo — Aplica um aviso (fica no histórico)
  • /mod mute @usuario duracao — Silencia por tempo definido. Exemplos de duração: 10m, 1h, 2d (máx. 28 dias)
  • /mod kick @usuario motivo — Expulsa o membro (pode voltar)
  • /mod ban @usuario motivo — Bane o membro permanentemente
  • /mod historico @usuario — Ver todos os casos de um membro
  • /mod casos — Listar casos recentes do servidor
  • /mod remover caso:123 — Inativar um caso pelo número

⭐ XP e Níveis

Sistema de gamificação: membros ganham XP ao enviar mensagens e sobem de nível, podendo ganhar cargos como recompensa.

/nivel / /top / /xp Ver e gerenciar o sistema de XP ✅ Qualquer membro
  • /nivel — Ver seu nível e XP atual (ou de outro membro)
  • /top — Ranking de XP do servidor
  • /xp config — Configurar o sistema: ativar/desativar, canal de notificação, XP por mensagem, cooldown
  • /xp recompensa-adicionar nivel:5 cargo:@Membro — Dar cargo automaticamente ao atingir um nível
  • /xp recompensa-remover nivel:5 — Remover recompensa de um nível
  • /xp recompensas — Listar todas as recompensas configuradas
  • /xp reset @usuario — Zerar o XP de um membro (admin)

🛡️ Auto-Moderação

O bot pode agir automaticamente contra spam, palavrões e links maliciosos sem precisar de um moderador online.

/automod Configurar regras automáticas de moderação 🔒 Gerenciar servidor
  • /automod ver — Exibir configuração atual
  • /automod spam ativo:sim mensagens:5 segundos:10 — Punir quem mandar 5+ msgs em 10s
  • /automod links ativo:sim — Bloquear links e convites do Discord
  • /automod mencoes limite:5 — Bloquear mensagens com mais de 5 menções
  • /automod raid ativo:sim entradas:10 segundos:30 — Alertar se 10 membros entrarem em 30s
  • /automod palavra-adicionar palavra:xingamento acao:mute — Bloquear palavra específica
  • /automod isentar-canal #canal — Canal onde o auto-mod não age
  • /automod isentar-cargo @cargo — Cargo que é ignorado pelo auto-mod

🔖 Tags

Respostas automáticas ativadas por prefixo no chat. Digite !ajuda e o bot responde automaticamente.

/tag Criar atalhos de resposta automática no chat 🔒 Gerenciar servidor (para criar)
  • /tag criar nome:regras conteudo:"Siga as regras do servidor!" — Criar tag
  • /tag editar nome:regras conteudo:"Novo texto" — Editar tag existente
  • /tag remover nome:regras — Apagar tag
  • /tag lista — Ver todas as tags do servidor
  • /tag ver nome:regras — Ver o conteúdo de uma tag
  • /tag prefixo prefixo:? — Mudar o prefixo (padrão: !)

Para usar uma tag no chat, basta digitar o prefixo + nome: !regras

❓ Perguntas frequentes

Os comandos não aparecem no Discord Como resolver

Os comandos slash são registrados automaticamente quando o bot inicia. Se não aparecerem:

  1. Verifique se o bot está Online no painel do DisCloud
  2. Certifique-se de que ao convidar o bot, você marcou o escopo applications.commands além de bot
  3. Se DEPLOY_GLOBAL=false, os comandos só aparecem nos servidores onde o bot está — aguarde até 1 minuto após o bot entrar no servidor
  4. Se DEPLOY_GLOBAL=true, pode demorar até 1 hora para o Discord propagar globalmente
Como convidar o bot para um servidor? Gerar o link de convite
  1. Acesse discord.com/developers e clique no seu app
  2. Vá em OAuth2 → URL Generator
  3. Marque os escopos: bot e applications.commands
  4. Em "Bot Permissions", marque: Administrator (ou as permissões específicas necessárias)
  5. Copie o link gerado e cole no navegador para convidar o bot
Posso usar o bot em vários servidores? Multi-servidor

Sim! O bot foi construído especificamente para isso. Cada servidor que adiciona o bot tem sua própria configuração independente. Um servidor nunca vê nem interfere nas configurações do outro.

O admin de cada servidor usa o /configurar e os outros comandos para personalizar o bot no seu servidor.

Os dados ficam salvos após reiniciar o bot? Persistência de dados

Sim. Todos os dados ficam salvos em um banco de dados SQLite no arquivo data/bot-ticket.db. O DisCloud mantém os arquivos da pasta data/ entre restarts e atualizações do bot.
